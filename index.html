Set 0

1. Theory: Explain TextView, EditText and Button in Android. How can font size, font style and text color be set?

TextView

  • A TextView (android.widget.TextView) is a GUI component that displays text to the user.
  • The user can only read the text, not edit it. It is used for labels, headings and messages.
  • Common attributes: android:text, android:textSize, android:textColor, android:textStyle, android:gravity.
  • In Java: setText("Hello") changes the text.

EditText

  • An EditText is a subclass of TextView that lets the user type and edit text, for example a name, password or number.
  • Common attributes: android:hint (grey placeholder text) and android:inputType (text, number, textPassword, phone, textEmailAddress).
  • In Java: String s = editText.getText().toString(); reads what the user typed.

Button

  • A Button is a subclass of TextView that the user taps to perform an action.
  • The tap is handled with setOnClickListener() in Java, or with android:onClick in XML.

Example (XML)

Example
<TextView
    android:text="Hello"
    android:textSize="20sp"
    android:textStyle="bold"
    android:textColor="#FF0000" />

<EditText
    android:hint="Enter your name"
    android:inputType="text" />

<Button
    android:text="Submit" />

Set 2

1. Theory: What are graphical primitives? Explain how Canvas and Paint are used to draw shapes in Android.

Graphical primitives

Graphical primitives are the basic shapes that all graphics are built from. Complex drawings are combinations of them.

  • Point: a single dot at (x, y)
  • Line: joins two points
  • Rectangle: four sides, given by left, top, right, bottom
  • Circle: given by a center (cx, cy) and a radius
  • Oval / Ellipse and Arc: drawn inside a rectangle
  • Text: a string drawn at a position

Canvas

  • Canvas (android.graphics.Canvas) is the drawing surface. It provides methods that draw each primitive.
  • Coordinates are in pixels. (0, 0) is the top-left corner; x increases to the right and y increases downward.
Canvas methodDraws
drawPoint(x, y, paint)a point
drawLine(x1, y1, x2, y2, paint)a line between two points
drawRect(left, top, right, bottom, paint)a rectangle
drawCircle(cx, cy, radius, paint)a circle
drawOval(left, top, right, bottom, paint)an oval inside that rectangle
drawText(text, x, y, paint)text
drawColor(color)fills the whole background

Paint

  • Paint (android.graphics.Paint) describes how to draw: color, thickness, fill and text size.
Paint methodPurpose
setColor(Color.RED)drawing color
setStrokeWidth(10)thickness of lines and outlines
setStyle(Paint.Style.FILL / STROKE)filled shape or outline only
setTextSize(60)size of text drawn with drawText
setAntiAlias(true)smooth edges

Steps to draw shapes

  1. Create a class that extends View.
  2. Override onDraw(Canvas canvas). Android calls it automatically whenever the view is shown.
  3. Create a Paint object and set its color, stroke width and text size.
  4. Call the Canvas draw methods, for example canvas.drawCircle(700, 450, 150, paint).
  5. Show the view with setContentView(new MyView(this)). Calling invalidate() redraws it.

package com.example.set2;

import android.graphics.Canvas;
import android.graphics.Color;
import android.graphics.Paint;
import android.os.Bundle;
import android.view.View;
import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {
    protected void onCreate(Bundle b) {
        super.onCreate(b);
        setContentView(new View(this) {
            protected void onDraw(Canvas c) {
                Paint p = new Paint();
                p.setStrokeWidth(10);
                p.setTextSize(60);

                p.setColor(Color.RED);
                c.drawLine(100, 200, 900, 200, p);         // line

                p.setColor(Color.BLUE);
                c.drawRect(100, 300, 450, 600, p);         // rectangle

                p.setColor(Color.GREEN);
                c.drawCircle(700, 450, 150, p);            // circle

                p.setColor(Color.BLACK);
                c.drawText("Hello Graphics", 100, 800, p); // text
            }
        });
    }
}

Click the green ▶ Run button (see How to run).

Output: a red line, a blue rectangle, a green circle and the text "Hello Graphics".

How it works: Instead of an XML layout, the app shows a custom View. Android calls its onDraw() with a Canvas. Paint sets the color, thickness and text size, and drawLine, drawRect, drawCircle and drawText draw the primitives at the given (x, y) pixel positions.

Program 2: TCP Client–Server Chat Application

Aim: To develop a client–server chat application in Java using TCP sockets.

Theory

  • TCP (Transmission Control Protocol) is connection-oriented: a connection is made first, then data is sent reliably and in order.
  • The server creates a ServerSocket on a port (5050) and calls accept(), which waits for a client. The client connects with new Socket("localhost", 5050).
  • Messages are sent with PrintWriter and received with BufferedReader.
  • The chat is turn by turn: the client sends a message, then the server replies, and so on. Typing bye ends the chat.
STEP 1 Save the two files in a folder named TCPChat
ChatServer.java
import java.io.*;
import java.net.*;

public class ChatServer {
    public static void main(String[] args) throws Exception {
        ServerSocket server = new ServerSocket(5050);
        System.out.println("Server started. Waiting for client...");
        Socket s = server.accept();
        System.out.println("Client connected. Type 'bye' to exit.");

        BufferedReader in = new BufferedReader(new InputStreamReader(s.getInputStream()));
        PrintWriter out = new PrintWriter(s.getOutputStream(), true);
        BufferedReader kb = new BufferedReader(new InputStreamReader(System.in));

        while (true) {
            String msg = in.readLine();                  // receive from client
            if (msg == null || msg.equalsIgnoreCase("bye")) break;
            System.out.println("Client: " + msg);

            System.out.print("Server: ");
            String reply = kb.readLine();                // type a reply
            out.println(reply);                          // send to client
            if (reply.equalsIgnoreCase("bye")) break;
        }
        System.out.println("Chat ended.");
        s.close();
        server.close();
    }
}
ChatClient.java
import java.io.*;
import java.net.*;

public class ChatClient {
    public static void main(String[] args) throws Exception {
        Socket s = new Socket("localhost", 5050);
        System.out.println("Connected to server. Type 'bye' to exit.");

        BufferedReader in = new BufferedReader(new InputStreamReader(s.getInputStream()));
        PrintWriter out = new PrintWriter(s.getOutputStream(), true);
        BufferedReader kb = new BufferedReader(new InputStreamReader(System.in));

        while (true) {
            System.out.print("Client: ");
            String msg = kb.readLine();                  // type a message
            out.println(msg);                            // send to server
            if (msg.equalsIgnoreCase("bye")) break;

            String reply = in.readLine();                // receive from server
            if (reply == null || reply.equalsIgnoreCase("bye")) break;
            System.out.println("Server: " + reply);
        }
        System.out.println("Chat ended.");
        s.close();
    }
}

  2. Terminal 2: open another terminal in the same folder.
    java ChatClient
  3. Type a message in the client window and press Enter. Then type a reply in the server window and press Enter. Keep taking turns.
  4. Type bye in either window to end the chat.

Program 3: Java RMI (Remote Method Invocation): Date and Time Service

Aim: To develop a Java RMI application in which the client gets the current date and time from a remote server.

Theory

  • RMI lets a Java program call a method of an object that runs in another JVM, even on another computer, as if it were a local method.
  • Remote interface (DateService): extends Remote and lists the methods the client can call. Each method throws RemoteException.
  • Implementation (Server): extends UnicastRemoteObject and contains the real code of the method.
  • RMI Registry: a name service on port 1099. The server registers its object under a name with Naming.rebind, and the client finds it with Naming.lookup.
  • Stub: a client-side proxy created automatically. It sends the method call over the network and brings back the result.
STEP 1 Save the three files in a folder named RMI
DateService.java
import java.rmi.*;

public interface DateService extends Remote {
    String getDateTime() throws RemoteException;
}
Server.java
import java.rmi.*;
import java.rmi.registry.*;
import java.rmi.server.*;
import java.util.Date;

public class Server extends UnicastRemoteObject implements DateService {
    Server() throws RemoteException {
        super();
    }

    public String getDateTime() {
        return new Date().toString();
    }

    public static void main(String[] args) throws Exception {
        LocateRegistry.createRegistry(1099);
        Naming.rebind("rmi://localhost/DateService", new Server());
        System.out.println("RMI Server is ready...");
    }
}
Client.java
import java.rmi.*;

public class Client {
    public static void main(String[] args) throws Exception {
        DateService d = (DateService) Naming.lookup("rmi://localhost/DateService");
        System.out.println("Date and Time from server: " + d.getDateTime());
    }
}
STEP 2 Compile (once)

Open a terminal in the RMI folder:

javac DateService.java Server.java Client.java
STEP 3 Run
  1. Terminal 1: the server. Start it first, leave it open, and wait for "RMI Server is ready...".
    java Server
  2. Terminal 2: same folder.
    java Client
  3. The client prints the server's date and time. Run java Client again to get the updated time.
  4. To stop the server, press Ctrl+C in Terminal 1.

You don't need to run rmiregistry separately, because the server starts it with LocateRegistry.createRegistry(1099).

OUTPUT
Terminal 1: Server
> java Server
RMI Server is ready...
Terminal 2: Client
> java Client
Date and Time from server: Fri Oct 30 21:45:59 IST 2026

How it works: The server registers itself in the RMI registry as DateService. The client looks up that name and calls getDateTime(). The method runs on the server, and the date and time come back to the client.

Result: A Java RMI Date and Time service was developed and executed successfully.

Program 5: Two-Phase Commit (2PC) Protocol Using Coordinator and Participants

Aim: To implement the Two-Phase Commit protocol in Java with one coordinator and two participants using TCP sockets.

Theory

  • 2PC is an atomic commitment protocol for distributed transactions: either all participants commit, or all abort.
  • Coordinator: controls the transaction and makes the final decision. Participants: vote on whether they are ready.
  • Phase 1, Prepare (voting): the coordinator sends PREPARE to every participant, and each one replies YES (ready) or NO.
  • Phase 2, Commit / Abort: if all votes are YES, the coordinator sends COMMIT to everyone. If any vote is NO, it sends ABORT to everyone.
  • Drawback: it is a blocking protocol. If the coordinator crashes after PREPARE, the participants have to wait.
STEP 1 Save the two files in a folder named 2PC
Coordinator.java
import java.io.*;
import java.net.*;

public class Coordinator {
    public static void main(String[] args) throws Exception {
        int n = 2;   // number of participants
        ServerSocket server = new ServerSocket(6789);
        System.out.println("Coordinator waiting for " + n + " participants...");

        Socket[] s = new Socket[n];
        BufferedReader[] in = new BufferedReader[n];
        PrintWriter[] out = new PrintWriter[n];

        for (int i = 0; i < n; i++) {
            s[i] = server.accept();
            in[i] = new BufferedReader(new InputStreamReader(s[i].getInputStream()));
            out[i] = new PrintWriter(s[i].getOutputStream(), true);
            System.out.println("Participant " + (i + 1) + " connected");
        }

        // Phase 1: Prepare (voting)
        System.out.println("\nPhase 1: Sending PREPARE to all participants");
        for (int i = 0; i < n; i++) {
            out[i].println("PREPARE");
        }

        boolean allYes = true;
        for (int i = 0; i < n; i++) {
            String vote = in[i].readLine();
            System.out.println("Participant " + (i + 1) + " voted: " + vote);
            if (!"YES".equals(vote)) {
                allYes = false;
            }
        }

        // Phase 2: Commit or Abort
        String decision = allYes ? "COMMIT" : "ABORT";
        System.out.println("\nPhase 2: Decision = " + decision);
        for (int i = 0; i < n; i++) {
            out[i].println(decision);
            s[i].close();
        }
        server.close();
    }
}
Participant.java
import java.io.*;
import java.net.*;
import java.util.Scanner;

public class Participant {
    public static void main(String[] args) throws Exception {
        Socket s = new Socket("localhost", 6789);
        BufferedReader in = new BufferedReader(new InputStreamReader(s.getInputStream()));
        PrintWriter out = new PrintWriter(s.getOutputStream(), true);
        Scanner sc = new Scanner(System.in);

        System.out.println("Connected to coordinator");
        System.out.println("Coordinator says: " + in.readLine());   // PREPARE

        System.out.print("Ready to commit? (YES/NO): ");
        out.println(sc.nextLine().trim().toUpperCase());              // send vote

        System.out.println("Final decision: " + in.readLine());      // COMMIT or ABORT
        s.close();
    }
}
STEP 2 Compile (once)

Open a terminal in the 2PC folder:

javac Coordinator.java Participant.java
STEP 3 Run (3 terminals, all in the 2PC folder)
  1. Terminal 1: the coordinator. Start it first.
    java Coordinator
  2. Terminal 2: it waits until the second participant joins. That is normal.
    java Participant
  3. Terminal 3:
    java Participant
  4. Both participants now ask "Ready to commit? (YES/NO)". Type YES or NO in each one and press Enter.
  5. YES in both gives COMMIT. NO in either gives ABORT. Run all three again to try the other case.

To use 3 participants, change int n = 2; to int n = 3;, compile again, and open one more terminal running java Participant.
